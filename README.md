# FizzBuzz

## Description

A program that prints the numbers from 1 to 100 with the following rules:
- For multiples of three, print "Fizz" instead of the number
- For multiples of five, print "Buzz" instead of the number
- For numbers which are multiples of both three and five, print "FizzBuzz"

## Test Cases

The implementation covers the following test scenarios:

| Test Case | Input | Expected Output |
|-----------|-------|-----------------|
| Number case | 1, 2 | Returns the number |
| Fizz case | 3, 9 | Returns "Fizz" |
| Buzz case | 5, 10 | Returns "Buzz" |
| FizzBuzz case | 15, 30 | Returns "FizzBuzz" |

## Task
Use TDD to implement the function that turns a number into the FizzBuzz output.
